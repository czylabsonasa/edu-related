A rendőrök megkérdezték az MI-t, hogy egy bizonyos bűntény tettese hol tartózkodhat. Azt válaszolta, hogy a rendelkezésre álló információk alapján egy origó középpontú R>0R>0 sugarú körlap olyan pontjai melyek koordinátáinak abszolút értékei különböző prímszámok… Hány különböző helyen lehet a tettes (LL)?

Bemenet specifikáció

Az első sorban van TT az esetek száma. Ezután TT sor jön, mindegyikben az RR pzitív egész számmal.

1≤R≤500_0001\le R \le 500\_000

lattice-1

The police asked an AI where a certain crime’s perpetrator could be located. It answered that, based on available information, the possible locations are points within a circle of radius R>0R > 0 centered at the origin whose coordinates’ absolute values are different prime numbers… How many different locations could the perpetrator be at (LL)?

Input specification

The first line contains TT, the number of test cases. Then TT lines follow, each containing a positive integer RR.

Output specification

Output TT lines, each containing the requested number LL.

Constraints

1≤T≤1001\le T \le 100
1≤R≤500_0001\le R \le 500\_000

Sample input 1 

3
2
10
4000

Sample output 1 

0
48
1003096
