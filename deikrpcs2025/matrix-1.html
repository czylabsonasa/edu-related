matrix-1

Egy MM mátrix mezőin kell lépegetnünk egy tetszőlegesen választott kezdő mezőről indulva. Víszintes vagy függőleges irányban szomszédos mezőre léphetünk, de csak akkor ha a szomszédos mező értéke nagyobb mint amin állunk. Maximálisan hány lépést tudunk megtenni (SS)? Hány olyan mező van melyről indulva a maximálisan lehetséges lépést tudjuk megtenni (LL)?

Bemenet specifikáció

TT az esetek száma. Egy eset leírása: Első sor RR és CC a mátrix sorainak és oszlopainak száma. Ezután RR sor következik, miindegyikben CC egész számmal.

Kimenet specifikáció

TT sor, mindegyikben a keresett SS és LL számok.

Korlátok

1≤R≤1001\le R \le 100
1≤C≤1001\le C \le 100
1≤M≤1_0001\le M \le 1\_000

matrix-1

We need to walk on the cells of an MM matrix, starting from any chosen starting cell. We can move to a horizontally or vertically adjacent cell, but only if the adjacent cell’s value is greater than the one we’re standing on. What is the maximum number of steps we can take (SS)? How many cells are there from which we can take the maximum possible number of steps (LL)?

Input specification

TT is the number of test cases. Description of a test case: First line: RR and CC (number of rows and columns of the matrix). Then RR lines follow, each containing CC integers.

Output specification

TT lines, each containing the requested numbers SS and LL.

Constraints

1≤T≤1001\le T \le 100
1≤R≤1001\le R \le 100
1≤C≤1001\le C \le 100
1≤M≤1_0001\le M \le 1\_000
